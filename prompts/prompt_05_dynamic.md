# Prompt 05：进阶挑战 —— 动态渲染页面对比方案

```
如果目标网站是 Vue/React 动态渲染的（初始 HTML 里没有数据），
应该如何爬取？请给出两种方案的优劣对比，并挑一种实现：
要求同样输出 标题/时间/作者/链接 四个字段到 result_dynamic.csv，
并打印耗时，用于和 HTML 方案对比代码复杂度与运行效率。
```

## 结论

- 方案 A（推荐）：F12 找到页面数据接口，requests 直接请求
  （本实验用中新网 RSS：`/rss/scroll-news.xml`）——1 次请求、无解析开销；
- 方案 B：Playwright/Selenium 无头浏览器渲染后取 DOM——通用但依赖重、慢约一个数量级；
- 实测接口方案抓 12 条仅 1 次 HTTP 请求、约 1s 内完成，而 HTML 方案需
  13 次请求、约 26s（12 条详情页 × 2s 强制间隔）。详见实验报告"进阶挑战"一节。
