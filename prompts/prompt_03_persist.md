# Prompt 03：CSV 持久化与异常处理（步骤 3）

```
解析逻辑已验证正确。现在把数据写入 result.csv，并补充异常处理：
约束：1) 字段缺失时填空字符串，避免程序崩溃；
2) 网络超时重试 3 次；3) 详情页抓"作者：xxx"字段，取不到填空串；
4) 请求间隔保持不低于 2 秒；5) CSV 用 UTF-8 编码。
验收：运行完整脚本，result.csv 编码为 UTF-8、列名为 标题/时间/作者/链接、
数据行数与打印的成功条数一致，且能用 Excel 正常打开不乱码。
```

## 迭代记录

- AI 初版用 `encoding="utf-8"` 写 CSV，Windows Excel 打开中文乱码；
  反馈后改为 `utf-8-sig`（带 BOM 的 UTF-8），Excel 兼容且仍是 UTF-8 标准。
- AI 初版对单个详情页请求失败会直接崩溃；反馈后改为"失败返回 None，
  作者填空字符串，不影响整体"。
- 验收结果：result.csv 列名正确、12 行数据与成功条数一致 → 通过（见 steps/step3_save.py）。
